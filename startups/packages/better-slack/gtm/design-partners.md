# Design Partner Program — COMM-025

Better Slack is recruiting **5 design partners** for a 90-day co-development period before public launch.

## Who we're looking for

- Engineering teams of 10–80 people
- Already using Slack + GitHub + Linear (or similar)
- Planning to deploy AI agents in production workflows
- Willing to give weekly feedback and tolerate v0.1 rough edges

## What partners get

| Benefit | Details |
|---------|---------|
| Free Team tier | 12 months post-launch ($0 during beta) |
| Direct founder access | Weekly 30-min sync, Slack channel with team |
| Roadmap influence | Vote on COMM task priorities |
| Early agent templates | CI Reporter, Linear sync, custom agents |
| Logo on launch page | Optional — "Built with" section |

## What we need from partners

1. **Onboard within 2 weeks** — import one Slack channel, connect GitHub
2. **Weekly feedback** — 15-min async or live check-in
3. **Case study participation** — anonymized metrics (thread resolution time, agent adoption)
4. **Reference call** — one 20-min call for prospects (post-launch)

## Application

Email `partners@better-slack.dev` with:

- Company name and team size
- Current comms stack (Slack, Discord, etc.)
- Top 3 pain points with async team communication
- Whether you have agents in production today

## Selection criteria

| Priority | Signal |
|----------|--------|
| High | Agent-heavy workflow (CI, incident, docs bots) |
| High | Forum-style discussions already (Notion, GitHub Discussions) |
| Medium | Remote-first, multiple time zones |
| Low | Teams seeking "Slack replacement" without agent use case |

## Timeline

| Week | Milestone |

| 3–6 | Core workflow validation (threads, posts, agents) |
