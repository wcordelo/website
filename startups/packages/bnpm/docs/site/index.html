Getting Started

bnpm is a drop-in wrapper around npm that blocks compromised packages before they reach your node_modules. It ships with embedded threat intelligence from real npm supply-chain incidents and enforces repo-level policy via .better-npmrc.

Use bunx @theo-startups/bnpm for zero-install trials, or add it as a dev dependency for CI. All commands support --json for machine-readable output.

Installation

# One-off
bunx @theo-startups/bnpm --help

# Project dev dependency
bun add -d @theo-startups/bnpm

# Global (optional)
npm install -g @theo-startups/bnpm

Quickstart

# 1. Scaffold policy + GitHub Action
bnpm init --strict

# 2. Install with blocklist gate
bnpm install

# 3. Audit CI workflows
bnpm audit-pipeline --sarif results.sarif

# 4. Publish with preflight + tarball diff
bnpm publish

.better-npmrc

Machine-readable policy checked into your repo:

blocklist = strict
lifecycle_scripts = allowlist
allowed_registries = https://registry.npmjs.org
require_provenance = @myorg/*
telemetry = off
script_allowlist = esbuild, prisma

Policy Modes

KeyValuesDescription
blockliststrict · warn · offThreat intel enforcement
lifecycle_scriptsallow · allowlist · block · warninstall script policy
telemetryopt-in · offAnonymous usage (default off)

command install

Pre-checks dependencies against the blocklist, then passthroughs to npm install.

bnpm install
bnpm install lodash
bnpm install --json

command ci

Strict CI install with blocklist gate and --ignore-scripts injection.

bnpm ci
bnpm ci --json

command init

Scaffolds .better-npmrc, optional strict .npmrc, and a GitHub Action workflow.

bnpm init
bnpm init --strict
bnpm init --force

flag --strict — applies hardened presets

flag --force — overwrite existing files

command publish

Interactive publish wizard with preflight checks and tarball diff vs previous registry version.

bnpm publish
bnpm publish --access public
bnpm publish --skip-preflight
bnpm publish --skip-tarball-diff

Preflight checks

  • Package metadata (name, version)
  • Blocklist gate on self-publish
  • Lifecycle script detection
  • Sigstore provenance (when configured)
  • Tarball diff vs previous version

command approve

Staged publish approval helper — generates staging URL and CI workflow snippet.

bnpm approve --package=my-pkg --version=1.2.3
bnpm approve --package=my-pkg --version=1.2.3 --approver=alice@corp.com

command shim

Package-manager-agnostic policy gate for pnpm and Yarn.

bnpm shim detect
bnpm shim check --json
bnpm shim install
bnpm shim init

Generates .pnpmfile.cjs and .yarnrc.yml snippets on shim init.

command audit-pipeline

Scans .github/workflows for supply-chain risks. Outputs SARIF for GitHub Security tab.

bnpm audit-pipeline
bnpm audit-pipeline --sarif results.sarif

command emergency

Emergency deprecate helper for compromised package versions (dry-run by default).

bnpm emergency deprecate
bnpm emergency deprecate --execute
bnpm emergency deprecate --package=axios@1.14.1

command bnpx

Alias invoked as bnpx — passthroughs to npx with JSON support.

bnpx cowsay hello
